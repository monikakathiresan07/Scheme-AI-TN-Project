# Scheme AI – Tamil Nadu Government Scheme Discovery & Eligibility Recommendation System

## 📌 About the Project

Scheme AI is a web-based application designed to help users discover suitable Tamil Nadu Government schemes based on their eligibility information.

The application makes government scheme information easier to understand and provides users with relevant scheme recommendations, eligibility details, required documents, application guidance, and official portal links.

## 🎯 Objectives

- Help users discover relevant government schemes
- Recommend schemes based on user eligibility information
- Make government scheme information easier to access
- Provide clear eligibility and document information
- Support users in understanding the application process
- Provide Tamil and English language support

## ✨ Key Features

- 🔍 Government Scheme Discovery
- 🎯 Eligibility-based Scheme Recommendation
- 🤖 Scheme AI Chatbot
- 🌐 Tamil and English Language Support
- 📋 Eligibility Information
- 📄 Required Documents Guidance
- 📝 Application Process Guidance
- 🔗 Official Government Portal Links
- 👤 User Profile and Dashboard

## 🧠 AI-Based Features

The project includes AI-oriented application features such as:

- Scheme recommendation based on user-provided eligibility information
- Natural-language search for scheme discovery
- Chatbot-based interaction
- Eligibility matching and recommendation logic

🚀 Getting Started
Prerequisites

Make sure Node.js is installed on your system.

Installation

Clone the repository:

git clone https://github.com/monikakathiresan07/Scheme-AI-TN-Project.git

Open the project folder:

cd Scheme-AI-TN-Project

Install dependencies:

npm install

Start the development server:

npm run dev

The application will then be available through the local development URL shown in the terminal.
