# Scheme AI – Tamil Nadu Government Scheme Discovery & Eligibility Recommendation System

## 📌 About the Project

Scheme AI is an AI-based application designed to help users discover suitable Tamil Nadu Government schemes based on their eligibility information.

The project aims to make government scheme information easier to understand and access for users.

## 🎯 Objectives

- Help users discover relevant government schemes
- Provide scheme recommendations based on user eligibility
- Present scheme benefits and eligibility information clearly
- Make government scheme discovery easier for users
- Support both Tamil and English

## ✨ Key Features

- Government Scheme Discovery
- Eligibility-based Recommendation
- User-friendly Interface
- Tamil and English Language Support
- Scheme Information and Benefits
- Eligibility Details

## 🛠️ Technologies

- Python
- HTML
- CSS
